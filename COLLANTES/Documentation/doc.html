Documentation for Helen - Personal Portfolio & CV HTML Template.

1. Introduction

Thank you for choosing Helen - Personal Portfolio Template.

This responsive portfolio template is ideal for personal portfolios, creative agencies, architects, photography studios, musicians, sound and music websites, painters, artists, illustrators, trainers, freelancers, web designers, and creative project showcases.

Choose the layout that best suits your needs, replace the demo text with your own content, add your images, and your professional portfolio website is ready to launch.

Helen is built with a clean and professional design, responsive layouts, SEO-friendly code, and easy customization in mind. We also provide a dedicated support team available 24/7 to help you with any questions or issues.

3. Requirements

Helen is a static HTML template, so no database or server-side installation is required.

  • A modern web browser
  • A code editor such as Visual Studio Code, Sublime Text, or Notepad++
  • Basic knowledge of HTML and CSS
  • Basic knowledge of JavaScript/jQuery for advanced customization
  • A web server or hosting account for publishing the website online

4. Installation

Follow the steps below to install and use the Helen template.

Step 1: Extract the Package

Extract the downloaded ZIP file on your computer.

Step 2: Open the Template

Open the extracted template folder using your preferred code editor.

Step 3: Customize the Template

Edit the HTML, CSS, and JavaScript files according to your requirements.

Step 4: Preview the Website

Open the main HTML file in your browser to preview your website.

Step 5: Upload to Your Server

When customization is complete, upload the template files to your hosting server using an FTP client or your hosting file manager.

6. Customization

Helen has been developed with easy customization in mind. You can customize the main website content directly from the HTML files.

For styling and design changes, use the CSS files located inside the assets/css folder.

For JavaScript functionality and interactive elements, use the JavaScript files located inside the assets/js folder.

Tip: Always keep a backup of the original files before making major changes.

7. Changing Text & Content

To change the text displayed on your website, open the relevant HTML file and locate the text you want to modify. 

<h1>Your Name</h1>
<p>Your professional description goes here.</p>

Replace the demo content with your own information.

  • Your name
  • Job title
  • About information
  • Skills
  • Services
  • Portfolio information
  • Contact information
  • Social media links
  • Other website content

8. Changing Images

You can replace the demo images with your own images.

Steps

  1. Open the assets/images folder.
  2. Add your new image.
  3. Find the corresponding image reference in the HTML file.
  4. Replace the existing image path with your new image path.
<img src="assets/images/your-image.jpg" alt="Your Name">

Image Recommendation

For better website performance, use optimized images in appropriate formats such as JPG, PNG, or WebP where applicable.

Use descriptive alt attributes for images to improve accessibility and SEO.

9. Changing Logo

To change the website logo, locate the logo image or logo markup in the relevant HTML file. 

<img src="assets/images/logo.png" alt="Helen">

Replace logo.png with your own logo file.

If the template uses text-based branding, simply replace the existing text with your preferred website or personal brand name.

10. Changing Colors & Styles

The visual appearance of Helen can be customized through the CSS files.

Locate the main stylesheet inside: 

assets/css/

Search for the relevant CSS selectors and modify the values according to your design requirements.

  • Background colors
  • Text colors
  • Button colors
  • Typography
  • Spacing
  • Borders
  • Hover effects
  • Font sizes
Tip: Keep a backup copy of the original CSS file before making significant changes.

11. Fonts

Helen uses Google Fonts for typography.

You can change the font by updating the Google Fonts reference in the HTML file or modifying the corresponding CSS font-family declaration. 

body {
    font-family: 'Your Font', sans-serif;
}

12. Icons

Helen uses Font Awesome icons.

You can change an icon by replacing the relevant Font Awesome class. 

<i class="fa fa-user"></i>

13. JavaScript & jQuery

14. SEO & Performance

Helen follows a clean HTML structure and is designed with SEO-friendly markup in mind.

For the best SEO results after customization, we recommend:

  • Use descriptive page titles.
  • Add relevant meta descriptions.
  • Use meaningful heading tags.
  • Add descriptive alt text to images.
  • Use clean and descriptive URLs.
  • Keep images optimized.
  • Replace all demo content with original content.
  • Submit your website to relevant search engine tools after launch.

Please note that an SEO-friendly template structure alone does not guarantee search engine rankings. Website content, technical SEO, performance, backlinks, and overall SEO strategy can also affect search visibility.
